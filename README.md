# fetchargv

Fetch URLs and argv query parts with stable normalization.

**Site:** https://theworker02.github.io/fetchargv/

## Install / run

```bash
git clone https://github.com/theworker02/fetchargv.git
cd fetchargv
node src/cli.js
node --test
```
